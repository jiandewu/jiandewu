# Hi, I'm Jiande Wu

Data Manager / Data Scientist at the Center for Public Health Modeling and
Response (CPHMR), Clemson University, working on public health data and
infectious disease forecasting. Previously a Senior Bioinformatics Specialist
at LSU Health Sciences Center. Ph.D. in Electrical Engineering, University of
New Orleans.
